# 时间复杂度、空间复杂度
复杂度用==1;;大 O 记法==描述算法随输入规模 $n$ 增长时，**时间**或**空间**的变化趋势（看增长率，不看常数系数）。
## 大 O 记法要点
- **上界**：$O(f(n))$ 表示增长不超过 $f(n)$ 的某个常数倍。
- **忽略低阶项**：$O(n^2 + n) =$ ==1;;O(n^2)==。
- **忽略常数**：$O(2n) =$ ==1;;O(n)==。
- **分析时默认关注**==1;;最坏（Worst-Case）==情况，面试和工程选型也以此为主。
## 复杂度阶梯（从快到慢）
==1;;`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)`==
$n = 10$ 时的操作量级对比：

| 复杂度           | 操作量级             |
| :------------ | :--------------- |
| $O(1)$        | 1                |
| $O(\log n)$   | ~3               |
| $O(n)$        | 10               |
| $O(n \log n)$ | ~30              |
| $O(n^2)$      | ==1;;100==       |
| $O(2^n)$      | ==1;;1,024==     |
| $O(n!)$       | ==1;;3,628,800== |
# 时间复杂度
$T(n)$ 表示执行时间与 $n$ 的关系。

| 表示法           | 名称            | 核心特征       | 典型算法                 |
| :------------ | :------------ | :--------- | :------------------- |
| $O(1)$        | ==1;;常数==时间   | 与 $n$ 无关   | ==1;;哈希查找==          |
| $O(\log n)$   | ==1;;对数==时间   | 每步规模约减半    | ==1;;二分查找==          |
| $O(n)$        | ==1;;线性==时间   | 与 $n$ 成正比  | ==1;;找最大值==          |
| $O(n \log n)$ | ==1;;线性对数==时间 | 分治 + 线性合并  | ==1;;归并排序==          |
| $O(n^k)$      | ==1;;多项式==时间  | $k$ 为常数    | ==1;;冒泡排序== $O(n^2)$ |
| $O(2^n)$      | ==1;;指数==时间   | $n$ 稍大即不可用 | ==1;;斐波那契（朴素递归）==    |
| $O(n!)$       | ==1;;阶乘==时间   | 增长最快       | ==1;;全排列==           |
## 最好 / 最坏 / 平均
1. **最好（Best-Case）**：最理想输入下的耗时。
2. **最坏（Worst-Case）**：最差输入下的耗时——==1;;日常分析首选==。
3. **平均（Average-Case）**：所有输入的期望耗时。
# 空间复杂度
$S(n)$ 通常指==1;;辅助空间==（不含输入本身占用的空间）。
递归算法的空间复杂度与==1;;调用栈最大深度==直接相关。

| 表示法         | 名称          | 核心特征            | 典型算法                  |
| :---------- | :---------- | :-------------- | :-------------------- |
| $O(1)$      | ==1;;常数==空间 | 只用固定数量变量        | ==1;;选择排序（原地）==       |
| $O(\log n)$ | ==1;;对数==空间 | 递归深度约为 $\log n$ | ==1;;二分递归==           |
| $O(n)$      | ==1;;线性==空间 | 额外空间与 $n$ 成正比   | ==1;;频次统计 / 归并临时数组==  |
| $O(n^2)$    | ==1;;平方==空间 | 二维结构存配对关系       | ==1;;最长公共子序列 / 邻接矩阵== |
# PHP 代码示例
以下按复杂度分类，展示**典型写法**；完整可运行版本见文末「附录：完整 PHP 示例」。
## 时间复杂度
### O(1) — 常数时间(哈希查找)
```php
function accessArrayElement(array $arr, int $index) {
    return $arr[$index]; // O(1)
}
function hashLookup(array $hashMap, $key) {
    return $hashMap[$key] ?? null; // O(1)
}
```
### O(log n) — 对数时间(二分查找)
```php
function binarySearch(array $arr, $target): int {
    $left = 0;
    $right = count($arr) - 1;
    while ($left <= $right) { // 每轮区间减半 → O(log n)
        $mid = intdiv($left + $right, 2);
        if ($arr[$mid] === $target) return $mid;
        $arr[$mid] < $target ? $left = $mid + 1 : $right = $mid - 1;
    }
    return -1;
}
```
### O(n) — 线性时间(找最大值)
```php
function findMax(array $arr): int {
    if ($arr === []) return -1;
    for ($i = 1, $max = $arr[0]; $i < count($arr); $i++) { // O(n)
        if ($arr[$i] > $max) $max = $arr[$i];
    }
    return $max;
}
```
### O(n log n) — 线性对数时间(归并排序)
分治排序的通用模式：**递归深度** $O(\log n)$ × **每层合并/分区** $O(n)$。
```php
function merge(array $left, array $right): array {
    $result = []; $i = $j = 0;
    while ($i < count($left) && $j < count($right)) {
        $left[$i] <= $right[$j] ? $result[] = $left[$i++] : $result[] = $right[$j++];
    }
    return [...$result, ...array_slice($left, $i), ...array_slice($right, $j)];
}
function mergeSort(array $arr): array {
    $n = count($arr);
    if ($n <= 1) return $arr;
    $mid = intdiv($n, 2);
    return merge(
        mergeSort(array_slice($arr, 0, $mid)),
        mergeSort(array_slice($arr, $mid))
    ); // 递归 O(log n) + 合并 O(n)
}
```
### O(n²) — 平方时间(冒泡排序)
嵌套循环是最常见来源。
```php
function bubbleSort(array $arr): array {
    $n = count($arr);
    for ($i = 0; $i < $n; $i++) {              // O(n)
        for ($j = 0; $j < $n - $i - 1; $j++) { // O(n)
            if ($arr[$j] > $arr[$j + 1]) {
                [$arr[$j], $arr[$j + 1]] = [$arr[$j + 1], $arr[$j]];
            }
        }
    }
    return $arr;
}
```
### O(2ⁿ) — 指数时间(斐波那契)
```php
function fibonacci(int $n): int {
    if ($n <= 1) return $n;
    return fibonacci($n - 1) + fibonacci($n - 2); // 重复子问题 → O(2ⁿ)
}
```
### O(n!) — 阶乘时间(全排列)
```php
function permute(array &$nums, int $start, array &$result): void {
    if ($start === count($nums)) { $result[] = $nums; return; }
    for ($i = $start; $i < count($nums); $i++) {
        [$nums[$start], $nums[$i]] = [$nums[$i], $nums[$start]];
        permute($nums, $start + 1, $result);
        [$nums[$start], $nums[$i]] = [$nums[$i], $nums[$start]];
    }
}
```
## 空间复杂度
### O(1) — 常数空间(选择排序)
```php
function selectionSortInPlace(array &$arr): void {
    $n = count($arr);
    for ($i = 0; $i < $n; $i++) {
        $min = $i;
        for ($j = $i + 1; $j < $n; $j++) {
            if ($arr[$j] < $arr[$min]) $min = $j;
        }
        [$arr[$i], $arr[$min]] = [$arr[$min], $arr[$i]]; // 仅几个临时变量
    }
}
```
### O(log n) — 对数空间(二分递归)
```php
function binarySearchRecursive(array $arr, $target, int $left, int $right): int {
    if ($left > $right) return -1;
    $mid = intdiv($left + $right, 2);
    if ($arr[$mid] === $target) return $mid;
    return $arr[$mid] < $target
        ? binarySearchRecursive($arr, $target, $mid + 1, $right)
        : binarySearchRecursive($arr, $target, $left, $mid - 1);
    // 栈深 O(log n)
}
```
### O(n) — 线性空间(频次统计)
```php
function countFrequency(array $arr): array {
    $freq = [];
    foreach ($arr as $v) {
        $freq[$v] = ($freq[$v] ?? 0) + 1; // 最多 n 个键 → O(n)
    }
    return $freq;
}
```
### O(n²) — 平方空间(最长公共子序列)
```php
function longestCommonSubsequence(string $a, string $b): int {
    $m = strlen($a); $n = strlen($b);
    $dp = array_fill(0, $m + 1, array_fill(0, $n + 1, 0)); // O(m×n)
    for ($i = 1; $i <= $m; $i++) {
        for ($j = 1; $j <= $n; $j++) {
            $dp[$i][$j] = $a[$i - 1] === $b[$j - 1]
                ? $dp[$i - 1][$j - 1] + 1
                : max($dp[$i - 1][$j], $dp[$i][$j - 1]);
        }
    }
    return $dp[$m][$n];
}
```
# 复杂度速查
| 复杂度           | 时间特征 | 空间特征           | PHP 常见场景                      |
| :------------ | :--- | :------------- | :---------------------------- |
| $O(1)$        | 固定耗时 | 固定变量           | `isset`、数组下标、`array_push/pop` |
| $O(\log n)$   | 规模减半 | 递归栈 $\log n$ 层 | 有序数组二分查找                      |
| $O(n)$        | 单次遍历 | 线性辅助数组         | `foreach`、`array_map/filter`  |
| $O(n \log n)$ | 分治排序 | 视实现而定          | `usort`、`uasort`              |
| $O(n^2)$      | 双层循环 | 可能二维表          | 朴素排序、邻接矩阵                     |
| $O(2^n)$      | 指数分支 | 递归栈最深 $n$      | 朴素递归、子集枚举                     |
| $O(n!)$       | 全排列  | 存所有排列          | 回溯生成排列                        |
# 性能测量
用 `microtime` 和 `memory_get_usage` 做**相对比较**（绝对数值受环境干扰，仅作直观感受）。
```php
class ComplexityAnalyzer {
    public static function measureTime(callable $fn, ...$args): array {
        $start = microtime(true);
        $result = $fn(...$args);
        return ['result' => $result, 'time' => microtime(true) - $start];
    }
    public static function measureMemory(callable $fn, ...$args): array {
        $before = memory_get_usage();
        $result = $fn(...$args);
        return ['result' => $result, 'memory' => memory_get_usage() - $before];
    }
    public static function generateTestData(int $size, string $type = 'random'): array {
        return match ($type) {
            'sorted'  => range(0, $size - 1),
            'reverse' => range($size - 1, 0, -1),
            default   => array_map(fn() => rand(1, $size * 10), range(1, $size)),
        };
    }
}
// 示例：对比 n=1000 时不同排序
$data = ComplexityAnalyzer::generateTestData(1000);
echo 'bubble: ' . ComplexityAnalyzer::measureTime('bubbleSort', $data)['time'] . "s\n";
echo 'quick:  ' . ComplexityAnalyzer::measureTime('quickSort', $data)['time'] . "s\n";
```

```php
// --- O(1) ---
function accessArrayElement(array $arr, int $index) { return $arr[$index]; }

// --- O(log n) ---
function binarySearch(array $arr, $target): int {
    $left = 0; $right = count($arr) - 1;
    while ($left <= $right) {
        $mid = intdiv($left + $right, 2);
        if ($arr[$mid] === $target) return $mid;
        $arr[$mid] < $target ? $left = $mid + 1 : $right = $mid - 1;
    }
    return -1;
}

// --- O(n) ---
function findMax(array $arr): int {
    if ($arr === []) return -1;
    $max = $arr[0];
    for ($i = 1, $n = count($arr); $i < $n; $i++) {
        if ($arr[$i] > $max) $max = $arr[$i];
    }
    return $max;
}

// --- O(n log n) ---
function merge(array $left, array $right): array {
    $result = []; $i = $j = 0;
    while ($i < count($left) && $j < count($right)) {
        $left[$i] <= $right[$j] ? $result[] = $left[$i++] : $result[] = $right[$j++];
    }
    return [...$result, ...array_slice($left, $i), ...array_slice($right, $j)];
}
function mergeSort(array $arr): array {
    $n = count($arr);
    if ($n <= 1) return $arr;
    $mid = intdiv($n, 2);
    return merge(mergeSort(array_slice($arr, 0, $mid)), mergeSort(array_slice($arr, $mid)));
}
function quickSort(array $arr): array {
    if (count($arr) <= 1) return $arr;
    $pivot = $arr[0];
    $left = $middle = $right = [];
    foreach ($arr as $v) {
        $v < $pivot ? $left[] = $v : ($v === $pivot ? $middle[] = $v : $right[] = $v);
    }
    return [...quickSort($left), ...$middle, ...quickSort($right)];
}

// --- O(n²) ---
function bubbleSort(array $arr): array {
    $n = count($arr);
    for ($i = 0; $i < $n; $i++) {
        for ($j = 0; $j < $n - $i - 1; $j++) {
            if ($arr[$j] > $arr[$j + 1]) {
                [$arr[$j], $arr[$j + 1]] = [$arr[$j + 1], $arr[$j]];
            }
        }
    }
    return $arr;
}

// --- O(2ⁿ) ---
function fibonacci(int $n): int {
    return $n <= 1 ? $n : fibonacci($n - 1) + fibonacci($n - 2);
}

// --- O(n!) ---
function generatePermutations(array $nums): array {
    $result = [];
    $backtrack = function (array &$nums, int $start) use (&$backtrack, &$result) {
        if ($start === count($nums)) { $result[] = $nums; return; }
        for ($i = $start; $i < count($nums); $i++) {
            [$nums[$start], $nums[$i]] = [$nums[$i], $nums[$start]];
            $backtrack($nums, $start + 1);
            [$nums[$start], $nums[$i]] = [$nums[$i], $nums[$start]];
        }
    };
    $backtrack($nums, 0);
    return $result;
}

// --- 运行验证 ---
$arr = [1, 3, 5, 7, 9, 11];
echo 'binarySearch(9): ' . binarySearch($arr, 9) . "\n";
echo 'mergeSort: ' . implode(', ', mergeSort([38, 27, 43, 3, 9])) . "\n";
echo 'fibonacci(10): ' . fibonacci(10) . "\n";
echo 'permutations(3): ' . count(generatePermutations([1, 2, 3])) . "\n";
```
